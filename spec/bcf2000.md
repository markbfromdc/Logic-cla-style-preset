# Behringer BCF2000 Integration

**Version:** 3.0
**Last Updated:** 2026-04-05
**Controller:** Behringer BCF2000 (8 rotary push-encoders)

---

## Overview

The BCF2000's 8 rotary encoders map directly to Logic Pro's 8 Smart Control knobs. Each encoder controls one parameter on the active preset. When you select a different track, the encoders automatically update to control that track's Smart Controls.

---

## Hardware Setup

### BCF2000 Configuration

1. **Connect** BCF2000 via USB to Mac
2. **Power on** the BCF2000
3. **Set operating mode** to USB (hold EDIT, press STORE to cycle modes)
4. **Set encoder mode** to Relative (recommended for Smart Controls):
   - Encoders should send relative values, not absolute
   - This prevents parameter jumps when switching between tracks with different knob positions

### Encoder Mode: Relative vs. Absolute

| Mode | Behavior | Recommendation |
|------|----------|----------------|
| **Relative** | Sends increment/decrement messages | Recommended — no parameter jumps |
| **Absolute** | Sends absolute CC values (0–127) | Works but causes jumps when switching tracks |

For relative mode, configure the BCF2000 to send relative signed bit messages (CC type: Relative 1).

## Logic Pro Controller Assignments

### Automatic Setup (Recommended)

Logic Pro can auto-detect the BCF2000:

1. Open Logic Pro > **Settings > Control Surfaces > Setup**
2. If BCF2000 is not auto-detected, click **New > Install**
3. Select **Behringer BCF2000** from the list
4. Logic will map the 8 encoders to Smart Control knobs 1–8 automatically

### Manual Setup (Learn Mode)

If automatic setup doesn't work:

1. Open **Smart Controls** pane (press **B**)
2. Click the **External Assignment** icon (small "i" button)
3. For each knob:
   a. Click the Smart Control knob in the UI
   b. Click **Learn**
   c. Turn the corresponding BCF2000 encoder
   d. Logic maps the MIDI CC to that knob
   e. Click **Learn** again to stop learning
4. Repeat for all 8 encoders

## MIDI CC Mapping Table

### Default BCF2000 Encoder CC Assignments

| Encoder # | BCF2000 Default CC | Smart Control Knob | Label (Mixing Presets) |
|-----------|-------------------|-------------------|----------------------|
| 1 | CC 81 | Knob 1 | DRIVE |
| 2 | CC 82 | Knob 2 | BASS |
| 3 | CC 83 | Knob 3 | TREBLE |
| 4 | CC 84 | Knob 4 | DYNAMICS |
| 5 | CC 85 | Knob 5 | COLOR |
| 6 | CC 86 | Knob 6 | WIDTH |
| 7 | CC 87 | Knob 7 | SPACE |
| 8 | CC 88 | Knob 8 | OUTPUT |

**Note:** Default CCs vary by BCF2000 firmware version and preset. The actual CC numbers don't matter — Logic's Learn mode maps whatever CC the encoder sends.

### What Changes Per Preset

The physical encoder-to-knob mapping stays constant (encoder 1 = knob 1, etc.). What changes is the **parameter** each knob controls:

| Encoder | Mixing Preset | Bus Preset | FX Send | Mastering |
|---------|--------------|-----------|---------|-----------|
| 1 | DRIVE | DRIVE | DECAY/TIME | INPUT/DRIVE |
| 2 | BASS | BASS | PRE-DLY/FEED | LOW/BASS |
| 3 | TREBLE | TREBLE | DAMP | HIGH/TREBLE |
| 4 | DYNAMICS | DYNAMICS | LOW CUT | GLUE/DYNAMICS |
| 5 | COLOR | COLOR | COLOR/FLUTTER | LOUD/COLOR |
| 6 | WIDTH | WIDTH | WIDTH | WIDTH |
| 7 | SPACE | SPACE | SIZE/SATURATION | CEILING/FOCUS |
| 8 | OUTPUT | OUTPUT | OUTPUT | OUTPUT |

## BCF2000 Preset Storage

### Saving a BCF2000 Preset

The BCF2000 can store multiple presets internally:

1. Configure encoder CCs as desired
2. Press **STORE**
3. Select preset slot (1–32)
4. Press **STORE** again to confirm

### Recommended BCF2000 Presets

| Preset # | Purpose | Notes |
|----------|---------|-------|
| 1 | Smart Controls (Encoders) | Primary — maps encoders to SC knobs 1–8 |
| 2 | Faders (if needed) | Alternative — maps motorized faders to channel volumes |

## Workflow Tips

### Track Selection = Instant Preset Switch

When you select a different track in Logic Pro, the Smart Controls automatically update to that track's preset. The BCF2000 encoders now control the new track's parameters. This means:

- Select a vocal track → encoders control DRIVE/BASS/TREBLE/DYNAMICS/COLOR/WIDTH/SPACE/OUTPUT for that vocal
- Select the drum bus → encoders now control the drum bus preset's parameters
- Select the master bus → encoders control INPUT/LOW/HIGH/GLUE/LOUD/WIDTH/CEILING/OUTPUT

No reconfiguration needed — just select the track.

### Encoder Resolution

BCF2000 encoders send 7-bit MIDI (0–127 values). Logic Pro interpolates these to the parameter range. For fine-grained parameters (e.g., CEILING -3 to 0 dB = 3 dB range over 128 steps = ~0.023 dB per step), the resolution is excellent. For wide-range parameters (e.g., DRIVE 0 to +18 dB = 18 dB over 128 steps = ~0.14 dB per step), resolution is still adequate.

### Using Encoder Push

BCF2000 encoders can be pushed (pressed down). This can be mapped to:

- **Toggle bypass** for a plugin
- **Reset to default** for a parameter
- Not used by default in the MPD-CLA presets, but available for customization

## Troubleshooting

| Issue | Cause | Solution |
|-------|-------|----------|
| Encoder doesn't control anything | Not mapped in Logic | Use Learn mode to re-map |
| Parameter jumps when switching tracks | Absolute mode | Switch BCF2000 to Relative encoder mode |
| Encoder moves but parameter doesn't respond | Wrong MIDI channel | Ensure BCF2000 and Logic are on same MIDI channel |
| BCF2000 not detected | USB connection | Try different USB port, check System Preferences > MIDI |
| Encoder controls wrong knob | Mapping offset | Re-map using Learn mode for each encoder |
| Motorized faders move unexpectedly | Fader mode active | Switch to encoder-only mode |
